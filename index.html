סקיל ל־Claude שהופך תסריט לסרטון הסבר מונפש, בסגנון 3Blue1Brown, בעזרת Manim.

A Claude skill that turns a script into an animated explainer video, in the style of 3Blue1Brown, with Manim.

מה הסקיל עושהWhat the skill does

נותנים ל־Claude תסריט, והוא מוביל את כל הדרך עד לסרטון מוגמר. כל שלב נשמר ונדחף לריפו, וכל סצנה נשלחת אליכם לבדיקה ברגע שהיא מוכנה.

You give Claude a script, and it takes it all the way to a finished video. Every stage is saved and pushed to the repository, and every scene is sent to you for review as soon as it is ready.

  1. התסריט נשמר כמו שהוא.
  2. הגהה: תיקון שגיאות כתיב בלבד. כל דבר שאינו ודאי חוזר אליכם כשאלה.
  3. תכנון: חלוקה לסצנות, ולכל סצנה תוכנית מפורטת עם זמנים, כתוביות, נוסחאות מדויקות ותמונות שצריך להוריד.
  4. התקנה: Python, Manim, LaTeX ו־FFmpeg, ברקע.
  5. מימוש: כל סצנה נכתבת ב־Python, מרונדרת, נבדקת פריים אחר פריים ומתוקנת. אחר כך נשלחת אליכם, עם כתוביות ובלי.
  6. חיבור: סרטון אחד מכל הסצנות, עם קובץ כתוביות ועם גרסה שהכתוביות צרובות בה.
  1. The script is saved exactly as given.
  2. Proofreading: spelling only. Anything uncertain comes back to you as a question.
  3. The plan: the script is cut into scenes, each with a detailed plan: timings, subtitles, exact formulas, images to download.
  4. Toolchain: Python, Manim, LaTeX and FFmpeg are installed in the background.
  5. Implementation: each scene is written in Python, rendered, checked frame by frame and fixed, then sent to you, with and without subtitles.
  6. Assembly: one video out of all the scenes, with a subtitle file and a version with the subtitles burned in.

התקנהInstalling

הסקיל צריך סביבה שבה Claude מריץ פקודות ומתקין חבילות: Claude Code, במחשב שלכם (טרמינל או אפליקציה) או בענן (claude.ai/code). את כל הכלים הוא מתקין בעצמו.

The skill needs an environment where Claude runs commands and installs packages: Claude Code, on your computer (terminal or app) or in the cloud (claude.ai/code). It installs all the tools itself.

שימושUsing it

  1. פותחים את Claude Code בריפו שבו ישמר הסרטון.
  2. מבקשים סרטון ומדביקים את התסריט. למשל: „תעשה מזה סרטון מאנים”, או הפרומפט המוכן. בלי תסריט, Claude כותב את הסקיל ומחכה.
  3. עונים על שאלות ההגהה. כל שאלה מסומנת בתווית (P1, P2, …), אז אפשר לענות בציטוט התווית.
  4. צופים בכל סצנה כשהיא מגיעה. הערות נותנים לפי מספר הסצנה והשנייה בה („סצנה 5, שנייה 12: הזום מהיר מדי”), או לפי הזמן בסרטון המלא.
  5. כל תיקון מרונדר מחדש ונשלח שוב. רק אחרי שכל הסצנות נשלחו, הן מחוברות לסרטון אחד.
  1. Open Claude Code in the repository the video should live in.
  2. Ask for a video and paste the script: "make a Manim video of this", or use the ready prompt. Without a script, Claude only reads the skill and waits.
  3. Answer the proofreading questions. Each has a tag (P1, P2, …), so you can answer by quoting it.
  4. Watch each scene as it arrives. Give notes by scene and second ("scene 5, second 12: the zoom is too fast"), or by the time in the full video.
  5. Every fix is rendered again and sent again. The scenes are joined into one video only once every one of them has been delivered.

כדאי לדעת

Good to know

  • סוגריים עגולים הם חלק מהקריינות ומופיעים בכתוביות. הוראות כותבים רק בסוגריים מרובעים.
  • סוגריים מרובעים בתוך נוסחה הם מתמטיקה, למשל $[0,1]$ או $\left[\frac{n}{p}\right]$, ולא הוראה. במקרה של ספק, Claude שואל.
  • ההוראות יכולות להיות קצרות וחלקיות, למשל „[הגרף עובר לסקלה לוגריתמית]”. Claude משלים את הפרטים ומסמן בתוכנית כל החלטה שלו ב־[fill], כדי שתראו מה הוא הוסיף.
  • הוראה עומדת ליד המשפט שהיא שייכת אליו. האנימציה מתחילה עם המשפט שמדבר עליה, ולא אחריו.
  • תמונות (דיוקנאות וכדומה) מבקשים בהוראה, למשל „[מופיעה תמונה של גאוס]”. Claude מוריד אותן ממקורות חופשיים.
  • קצב ההקראה הוא 5.05 הברות לשנייה, ונוסחה נספרת לפי ההקראה שלה (r1% נקראת „אר אחוז”). אפשר לבקש קצב אחר.
  • ההוראות הן משאלות, לא קוד. אפשר לכתוב „[הזום צריך להיות איטי]” או „[המספר הופך ל־10^6 תוך כדי תנועה]”.
  • Parentheses belong to the narration and appear in the subtitles. Directions go in square brackets only.
  • Square brackets inside a formula are mathematics ($[0,1]$, $\left[\frac{n}{p}\right]$), not a direction. When it is unclear, Claude asks.
  • Directions can be short and incomplete, e.g. "[the graph switches to a log scale]". Claude fills in the details, and marks each of its own decisions in the plan with [fill] so you can see what it added.
  • Put a direction next to the sentence it belongs to. An animation starts with the sentence that speaks of it, not after it.
  • Images (portraits and the like) are asked for in a direction, e.g. "[a portrait of Gauss appears]". Claude downloads them from free sources.
  • The reading rate is 5.05 syllables per second, a formula counted as it is read aloud (r1% is "r percent"). Ask for another rate if you like.
  • Directions are wishes, not code. You can write "[the zoom should be slow]" or "[the number turns into 10^6 while moving]".

דוגמה

Example

קחו מספר גדול. לדוגמה עשרת אלפים [המספר מופיע על ציר המספרים]. מה הסיכוי שהוא יהיה ראשוני?

נגריל מספר שסוטה מעשרת אלפים בלא יותר מאחוז אחד (כלומר בלא יותר ממאה) [התחום מסומן על ציר המספרים], ונשאל מה ההסתברות שהוא ראשוני.

[חלון בגודל 1% גולש לאורך הציר, ומעליו נבנה גרף ההסתברות]
נסמן את הפונקציה הזאת ב-$p_{1\%}(n)$. היא מקבלת ערכים בקטע $[0,1]$.
Take a large number, say ten thousand [the number appears on the number line]. What is the chance that it is prime?

Draw a number at most one percent away from ten thousand (that is, at most a hundred away) [the range is marked on the line], and ask how likely it is to be prime.

[a 1% window slides along the axis, and the graph of the probability is traced above it]
Call this function $p_{1\%}(n)$. Its values lie in $[0,1]$.

בשחור: קריינות (כולל הסוגריים העגולים). באדום: הוראות. בכחול: נוסחאות, והסוגריים המרובעים שבתוכן הם מתמטיקה.

Black: narration (parentheses included). Red: directions. Blue: formulas, whose square brackets are mathematics.
